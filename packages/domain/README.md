# @timcontrol/domain

Regras de negócio puras: sem banco, sem rede, sem Next.js. Tudo aqui é testável com Vitest sem infraestrutura.

- `invites.ts`: validade e estado do convite.
- `matrix.ts`: edição da matriz de permissões (o que pode ser gravado em cada perfil).

Os cards, responsáveis e prazos entram aqui no Lote 2.
